Curious by default.
Practical by design.

Still early in the journey — focused on building a strong foundation, one project and one concept at a time.

I’m currently studying Computer Science at VIT Vellore. I learn best when I can connect a concept to something real: a model that makes a forecast, a web app with separate user roles, or an AI workflow that helps people find what they need.

01 —

Start with the real problem

Define the user, the input, the expected output, and what a useful result looks like before reaching for a framework.

02 —

Make a small, testable version

Build the end-to-end path first, then separate components and add complexity when it earns its place.

03 —

Measure, debug, and document

Use tests and metrics where possible, write down limitations, and make the project easier for the next person to run.

04 —

Keep the fundamentals in view

Tools can speed up implementation, but I want to understand the data flow, edge cases, and trade-offs behind the result.
